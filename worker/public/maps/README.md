# 房区底图

`worker/public/index.html` 的房区图用的底图，Workers 直接当静态资源发出去，路径 `/maps/文件名`。

## 命名

`{房区}-0.jpg`，只要 5 张（只需要主城区）：

| 文件 | 房区 |
|---|---|
| `0-0.jpg` | 海雾村 |
| `1-0.jpg` | 薰衣草苗圃 |
| `2-0.jpg` | 高脚孤丘 |
| `3-0.jpg` | 白银乡 |
| `4-0.jpg` | 穹顶皓天 |

**扩建区不需要单独出图**：它就是主城区整体顺时针转 90° 再平移，
页面里用 `transform="translate(-704,-704) rotate(90)"` 现算，五个房区都一样。

## 换图时的要求

- 2048×2048 的整图，不要裁剪。
- 换算关系写死在代码里：`像素 = 世界坐标 × 2 + 1024`，
  也就是整张图在世界坐标系里正好是 (-512,-512)~(512,512)。
  只要还是 2048 整图，换一张新的不用改任何代码；裁过的图会对不上。
